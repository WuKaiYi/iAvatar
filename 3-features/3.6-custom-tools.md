# 3.6 自定义工具系统

## 概述

LearningVerse平台提供了一套强大的自定义工具系统，用于处理各种资源的加载、场景编辑和UI管理。这些工具使开发者能够轻松地集成和管理3D模型、图片、网页链接等资源，并提供了完整的网络同步支持。

## 核心组件

### CustomLoader 资源加载器

CustomLoader是一个多功能的资源加载组件，支持以下类型的资源：

- 图片（Image）
- 3D模型（Model3D）
- 网页链接（WebLink）
- 任务标记（TaskFlag）
- 聊天面板（ChatBoard）

```csharp
public enum DataType
{
    Image,
    Model3D,
    WebLink,
    TaskFlag,
    ChatBoard,
    other
}
```

#### 主要功能

1. **图片加载**
   - 支持多种图片格式
   - 自动处理图片缩放和显示
   - 集成IMBX图片加载系统

2. **3D模型加载**
   - 支持GLTF格式模型
   - 自动处理模型缩放和位置调整
   - 支持动画播放

3. **网页链接集成**
   - 内置网页浏览器支持
   - 自动处理键盘输入
   - 支持页面刷新和导航

4. **网络同步**
   - 支持多用户场景同步
   - 资源状态自动同步
   - 支持动态编辑模式

### CustomToolInitializer 工具初始化器

CustomToolInitializer负责管理工具系统的初始化和场景生成：

- 场景保存和加载
- 工具状态管理
- 小地图生成
- 截图功能

### 建筑系统UI

CustonUIBuildingMenu提供了直观的建筑系统界面：

- 分类管理建筑部件
- 支持价格系统
- 自定义建筑按钮
- 实时预览功能

## 使用示例

### 1. 加载3D模型

```csharp
// 创建CustomLoader实例
CustomLoader loader = gameObject.AddComponent<CustomLoader>();
loader.dataType = CustomLoader.DataType.Model3D;
loader.data = "模型文件路径";
loader.LoadData();
```

### 2. 添加网页链接

```csharp
// 设置网页链接
CustomLoader webLoader = gameObject.AddComponent<CustomLoader>();
webLoader.dataType = CustomLoader.DataType.WebLink;
webLoader.data = "https://example.com";
webLoader.LoadData();
```

### 3. 创建建筑菜单

```csharp
// 配置建筑菜单类别
[Serializable]
public class BuildingMenuCategory
{
    public string Name;
    public BuildingPart[] Items;
}
```

- 多用户编辑

- 地牢生成

## 最佳实践

1. **资源管理**
   - 使用适当的资源类型
   - 优化资源加载
   - 合理设置缓存

2. **性能优化**
   - 控制同时加载的资源数量
   - 使用异步加载
   - 及时释放未使用的资源

3. **网络同步**
   - 使用适当的同步频率
   - 处理网络延迟
   - 实现错误恢复机制

## 故障排除

1. **资源加载失败**
   - 检查文件路径
   - 验证文件格式
   - 确认网络连接

2. **网络同步问题**
   - 检查网络连接
   - 验证权限设置
   - 查看同步状态

3. **UI显示异常**
   - 检查Canvas设置
   - 验证事件系统
   - 更新UI组件
